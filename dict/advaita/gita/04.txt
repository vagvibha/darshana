श्रीभगवानुवाच
इमं विवस्वते योगं प्रोक्तवानहमव्ययम्।
विवस्वान्मनवे प्राह मनुरिक्ष्वाकवेऽब्रवीत्॥४।१॥
====
+ e:BG-04-01;मनु;वच्+क्तवतु;प्रोक्तवत्;प्र+अह्;ब्रू;प्र+वच्+क्तवतु;इक्ष्वाकु;विवस्वत्
++ अहम् इमम् अव्ययम् योगम् विवस्वते प्रोक्तवान्। विवस्वान् मनवे प्राह। मनुः इक्ष्वाकवे अब्रवीत्
‹ <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-02">॥४।२॥</a> ›

एवं परम्पराप्राप्तमिमं राजर्षयो विदुः।
स कालेनेह महता योगो नष्टः परन्तप॥४।२॥
====
+ e:BG-04-02;नश्+क्त;राजर्षि;प्राप्त;आप्+क्त;नश्;परम्परा;प्राप्;परम्पराप्राप्त;प्राप्+क्त;नष्ट
++ परन्तप, एवम् परंपराप्राप्तम् इमम् (योगम्) राजर्षयः विदुः। सः योगः इह महता कालेन नष्टः
‹ <a href="bword://BG-04-01">॥४।१॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-03">॥४।३॥</a> ›

स एवायं मया तेऽद्य योगः प्रोक्तः पुरातनः।
भक्तोऽसि मे सखा चेति रहस्यं ह्येतदुत्तमम्॥४।३॥
====
+ e:BG-04-03;रहस्य;भक्त;प्रोक्त;भज्+क्त;प्र+वच्+क्त;भज्;सखि;पुरातन
++ सः एव अयम् पुरातनः योगः अद्य मया ते प्रोक्तः, (यतः त्वम्) मे भक्तः सखा च असि इति। हि एतत् उत्तमम् रहस्यम् (अस्ति)
‹ <a href="bword://BG-04-02">॥४।२॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-04">॥४।४॥</a> ›

अर्जुन उवाच
अपरं भवतो जन्म परं जन्म विवस्वतः।
कथमेतद्विजानीयां त्वमादौ प्रोक्तवानिति॥४।४॥
====
+ e:BG-04-04;वि+ज्ञा;जन्मन्;वच्+क्तवतु;प्रोक्तवत्;प्र+वच्+क्तवतु;अपर;आदि;भवत्;विवस्वत्
++ भवतः जन्म अपरम्, विवस्वतः जन्म परम्। त्वम् आदौ प्रोक्तवान् इति एतत् कथम् विजानीयाम्?

श्रीभगवानुवाच
बहूनि मे व्यतीतानि जन्मानि तव चार्जुन।
तान्यहं वेद सर्वाणि न त्वं वेत्थ परन्तप॥४।५॥
====
+ e:BG-04-05;इ+क्त;जन्मन्;वि+अति+इ+क्त;व्यतीत;वि+अति+इ;बहु
++ अर्जुन, मे बहूनि जन्मानि व्यतीतानि, तव च। परन्तप, अहम् तानि सर्वाणि वेद, त्वम् न वेत्थ
‹ <a href="bword://BG-04-04">॥४।४॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-06">॥४।६॥</a> ›

अजोऽपि सन्नव्ययात्मा भूतानामीश्वरोऽपि सन्।
प्रकृतिं स्वामधिष्ठाय सम्भवाम्यात्ममायया॥४।६॥
====
+ e:BG-04-06;स्था+ल्यप्;आत्म;सत्;अज;आत्ममाया;माया;अधि+स्था;अधिष्ठाय;सम्+भू;अधि+स्था+ल्यप्;स्व;अव्ययात्मन्;अस्+शतृ
++ अजः अपि सन्, अव्ययात्मा (अपि सन्), भूतानाम् ईश्वरः अपि सन्, स्वाम् प्रकृतिम् अधिष्ठाय आत्ममायया सम्भवामि
‹ <a href="bword://BG-04-05">॥४।५॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-07">॥४।७॥</a> ›

यदा यदा हि धर्मस्य ग्लानिर्भवति भारत।
अभ्युत्थानमधर्मस्य तदात्मानं सृजाम्यहम्॥४।७॥
====
+ e:BG-04-07;ग्लानि;अधर्म;अभ्युत्थान;सृज्
++ भारत, यदा यदा हि धर्मस्य ग्लानिः अधर्मस्य च अभ्युत्थानम् भवति, तदा अहम् आत्मानम् सृजामि
‹ <a href="bword://BG-04-06">॥४।६॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-08">॥४।८॥</a> ›

परित्राणाय साधूनां विनाशाय च दुष्कृताम्।
धर्मसंस्थापनार्थाय सम्भवामि युगे युगे॥४।८॥
====
+ e:BG-04-08;परित्राण;धर्मसंस्थापनार्थ;विनाश;साधु;सम्+भू;युग;दुष्कृत्;संस्थापन
++ साधूनाम् परित्राणाय, दुष्कृताम् विनाशाय च, धर्मसंस्थापनार्थाय (अहम्) युगे युगे सम्भवामि
‹ <a href="bword://BG-04-07">॥४।७॥</a> · <a href="bword://BG-04">BG-04</a> · <a href="bword://BG-04-09">॥४।९॥</a> ›

जन्म कर्म च मे दिव्यमेवं यो वेत्ति तत्त्वतः।
त्यक्त्वा देहं पुनर्जन्म नैति मामेति सोऽर्जुन॥४।९॥
====
+ e:BG-04-09;पुनर्जन्मन्;जन्मन्;तत्त्वतः
++ अर्जुन, यः मे दिव्यम् जन्म कर्म च एवम् तत्त्वतः वेत्ति, सः देहम् त्यक्त्वा पुनः जन्म न एति, माम् एति

वीतरागभयक्रोधा मन्मया मामुपाश्रिताः।
बहवो ज्ञानतपसा पूता मद्भावमागताः॥४।१०॥
====
+ e:BG-04-10;भय;मद्भाव;पू;वीत;मन्मय;बहु;आ+गम्+क्त;तपस्;श्रि+क्त;उप+आ+श्रि+क्त;आगत;श्रि;उपाश्रित;आ+गम्;राग;पूत;ज्ञानतपस्;वीतरागभयक्रोध;पू+क्त;उप+आ+श्रि

ये यथा मां प्रपद्यन्ते तांस्तथैव भजाम्यहम्।

+ e:BG-04-11;भज्;सर्वशः;पद्;मनुष्य;वर्त्मन्;प्र+पद्;अनु+वृत्

====
+ e:BG-04-12;मानुष;काङ्क्ष्+शतृ;क्षिप्रम्;देवता;सिद्धि;जा;यज्;काङ्क्षत्;कर्मजा;काङ्क्ष्
++ इह कर्मणाम् सिद्धिम् काङ्क्षन्तः देवताः यजन्ते। हि मानुषे लोके कर्मजा सिद्धिः क्षिप्रम् भवति

चातुर्वर्ण्यं मया सृष्टं गुणकर्मविभागशः।

====
+ e:BG-04-13;कर्तृ;सृष्ट;सृज्;गुणकर्मविभागशः;सृज्+क्त;चातुर्वर्ण्य;विभागशः;अकर्तृ

न मां कर्माणि लिम्पन्ति न मे कर्मफले स्पृहा।

====
+ e:BG-04-14;बन्ध्;कर्मफल;लिप्;स्पृहा;अभि+ज्ञा

एवं ज्ञात्वा कृतं कर्म पूर्वैरपि मुमुक्षुभिः।

====
+ e:BG-04-15;मुच्;पूर्वतर;मुच्+सन्+उ;मुमुक्षु;पूर्व;कृत
