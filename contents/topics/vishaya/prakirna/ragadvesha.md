## रागद्वेषाः

### षोडशविधो रागद्वेषादिः

रागो द्वेषः कामः क्रोधो लोभो मोहो मदो
मात्सर्यमीर्ष्याऽसूया दम्भो दर्पोऽहङ्कार इच्छा भक्तिः श्रद्धेति रागद्वेषादिवृत्तयः षोडश ।

| वृत्तिः | शुद्धा/अशुद्धा | परिभाषा |
|----|----|----|
| रागः | अशुद्धा | स्त्रीविषयकचित्तवृत्ती रागः। |
| द्वेषः | अशुद्धा | अपकारकर्तुः प्रत्यपकारेच्छा द्वेषः। |
| कामः | अशुद्धा | गृहक्षेत्रादिसम्पादनेच्छा कामः। |
| क्रोधः | अशुद्धा | तत्र विघ्नकर्तरि वैरस्यं क्रोधः। |
| लोभः | अशुद्धा | स्वसम्पादितेषु किञ्चिदपि सत्पात्रे न देयमिति बुद्धिर्लोभः। |
| मोहः | अशुद्धा | ऐश्वर्यमदेन कृत्याकृत्यमविचार्य तूष्णीमवस्थानं मोहः। |
| मदः | अशुद्धा | स्वस्य सम्पदस्ति, किं वा कर्तुमशक्यमिति बुद्धिर्मदः। |
| मात्सर्यम् | अशुद्धा | स्वसमानसम्पन्नजनदर्शनासहनं मात्सर्यम्। |
| ईर्ष्या | अशुद्धा | इदं दुःखं तं विहाय मम किमित्यागतमिति चित्तवृत्तिरीर्ष्या। |
| असूया | अशुद्धा | इदं सुखं ममैव तस्यापि किमित्यागतमिति बुद्धिरसूया। |
| दम्भः | अशुद्धा | अनेन धर्मेण मम प्रसिद्धिर्भूयादिति चित्तवृत्तिर्दम्भः। |
| दर्पः | अशुद्धा | मम न कोऽपि समान इति बुद्धिर्दर्पः। |
| अहङ्कारः | अशुद्धा | सर्वत्राग्रहोऽहङ्कारः। |
| इच्छा | अशुद्धा* | अवर्जनीयप्राशनविमोचनादिकर्मचिकीर्षा इच्छा। |
| भक्तिः | शुद्धा | गुरौ सज्जनेषु देवतासु चातिप्रीतिर्भक्तिः। |
| श्रद्धा | शुद्धा | यागादिकर्मसु वेदान्तवाक्येषु गुरूपदेशे च विश्वासः श्रद्धा। |

<sup>*</sup>अशुद्धापि त्यक्तुमशक्यम् ।

१४ चतुर्दशाः वृत्तयः अशुद्धाः, प्रयत्नं विना पौनपुन्येनोद्भवन्ति, पापेषु प्रवर्तयन्ति ।
